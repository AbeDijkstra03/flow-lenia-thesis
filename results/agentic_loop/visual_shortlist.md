# Visual Shortlist: Flow-Lenia Elites

Generated from the latest autonomous campaigns with a visual-first filter.

## Selection Criteria

- Must pass watertight quality gates.
- Must show a persistent dense core in the right-panel density view.
- Must show a coherent perimeter or lobe structure in the left-panel plasma view.
- Must show a non-trivial motion trail in the heatmap.
- Prefer elites with distinct morphology rather than near-duplicates.
